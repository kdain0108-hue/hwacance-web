# 디자인 명세 (design.md)

## 1. 목적

똥싸자 MVP의 색상, 타이포그래피, 배경 패턴, 화면별 시각 구성 규칙을 정의한다.
기능 동작은 각 기능 사양([`specs/`](./specs))이 소유하며, 이 문서는 시각적 표현만 소유한다.

## 2. 범위

- 색상 토큰
- 타이포그래피(픽셀 폰트 적용 범위)
- 배경 패턴(모눈 그리드)
- 버튼 컴포넌트 스타일
- 이미지 에셋 매핑

## 3. 색상

| ID | 요구사항 |
| --- | --- |
| DSN-01 | 메인 컬러는 흰색 `#FFFFFF`과 파란색 `#6485F6`이다. |
| DSN-02 | 보조 파란색 `#4C6BDB`은 강조 텍스트와 진행 상태에 사용한다. |
| DSN-03 | 타이머·부처되기 배경 그리드는 흰색 `#FFFFFF` 바탕에 옅은 파란색 선 `#E3EDFF`을 사용한다. |
| DSN-04 | 눈치껏 쉬자의 `아직은 눈치 봐야 해요` 문구는 `#6485F6`으로 표시한다. |

## 4. 타이포그래피

| ID | 요구사항 |
| --- | --- |
| DSN-05 | 앱 전체 기본 서체는 `Mona12`(픽셀 서체)다. |
| DSN-06 | 한글이 포함된 화면이므로 한글 전용 커팅인 `Mona12TextKR`을 임베드해 사용한다. |
| DSN-07 | `Mona12`가 렌더링하지 못하는 문자는 시스템 한글 서체(`Apple SD Gothic Neo`, `맑은 고딕`)로 대체한다. |
| DSN-08 | 자간과 줄 간격은 픽셀 서체의 각진 형태를 해치지 않는 범위에서 최소로 조정한다. |

### 4.1 서체 출처와 라이선스

- 서체 파일 출처: `C:\Users\user\Desktop\MY\활동 아카이빙\PPT\FONT`(사용자 로컬 보관 폰트)

## 5. 배경 패턴 — 모눈 그리드

| ID | 요구사항 |
| --- | --- |
| DSN-09 | 파란 선 모눈 그리드를 배경으로 사용한다. |
| DSN-10 | 그리드 격자 간격은 22px, 선 두께는 1px다(연한 선으로 본문을 가리지 않는다). |
| DSN-11 | 그리드는 장식이므로 본문 텍스트 대비를 낮추지 않는다(WCAG AA 유지). |

## 6. 버튼 컴포넌트

기존 앱(화장쉼 시작하기 등)에서 쓰인 알약형 버튼 스타일을 그대로 따른다.
똥싸자 시작 화면의 "똥 싸기 시작" 버튼([SPEC 01](./specs/01-core-gameplay.md))에도 동일한 스타일을 적용한다.

| ID | 요구사항 |
| --- | --- |
| DSN-12 | 버튼은 완전한 알약(캡슐) 형태다. `border-radius`는 버튼 높이의 50%로, 좌우 끝이 완전히 둥글다. |
| DSN-13 | 버튼 배경은 위(밝은 파란색)에서 아래(`#6485F6`)로 이어지는 그라디언트를 사용하고, 테두리는 보조 파란색 `#4C6BDB`로 감싼다. |
| DSN-14 | 버튼 좌상단에는 반투명 흰색 광택(하이라이트) 효과를 넣어 입체감을 준다. |
| DSN-15 | 버튼 라벨은 흰색, 굵게(Bold), 중앙 정렬하며 [4장 타이포그래피](#4-타이포그래피) 규칙(`Mona12`/`Mona12TextKR`)을 따른다. |
| DSN-16 | 버튼 하단에는 은은한 그림자(box-shadow)를 넣어 배경 위에 떠 있는 느낌을 준다. |

### 6.1 구현 예시

- [`start-button.svg`](./start-button.svg): 위 규칙을 적용한 "똥 싸기 시작" 버튼 예시 에셋.
