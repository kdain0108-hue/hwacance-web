# AGENTS.md

이 문서는 `ddongssaja` (💩 똥 싸자) 프로젝트에서 작업하는 AI 코딩 에이전트를 위한 가이드입니다.
게임 기획의 원본 소스는 [PRD.md](./PRD.md)이며, 구현/제안 시 항상 PRD를 기준으로 삼습니다.

## 프로젝트 개요

- 캐주얼 아케이드 생존형 스코어 게임
- 변기를 좌우로 움직여 떨어지는 똥을 받는 단일 코어 루프
- 시간 경과에 따라 낙하 속도가 증가하는 난이도 곡선
- 똥과 섞여 떨어지는 "휴지"는 방해 요소(득점 대상 아님)

## 작업 원칙

1. **PRD를 진실의 원천으로 삼기**: 규칙(득점 조건, 종료 조건, 난이도 상승 등)을 변경하거나
   확장할 때는 먼저 `PRD.md`를 갱신한 뒤 구현에 반영합니다. PRD와 코드가 어긋나면 안 됩니다.
2. **Open Questions 우선 확인**: `PRD.md`의 "향후 논의가 필요한 사항"에 있는 항목
   (조작 방식, 실패 조건, 기록 저장 방식, 난이도 곡선 수치, 사운드/아이템 여부)은
   아직 미확정입니다. 관련 기능을 구현하기 전에는 사용자에게 확인하거나, 합리적인 기본값을
   가정한 뒤 PRD에 그 결정을 기록합니다.
3. **최소 범위 구현**: 짧은 세션/단순 조작이라는 게임의 정체성에 맞게, 요청받지 않은 부가 기능
   (예: 인앱결제, 소셜 공유, 복잡한 아이템 시스템)을 임의로 추가하지 않습니다.
4. **작은 단위로 검증 가능하게**: 핵심 루프(낙하 → 드래그 → 판정 → 점수)를 먼저 동작하게 만들고,
   난이도 곡선/휴지 방해 요소는 그 위에 추가합니다.

## 핵심 게임 로직 체크리스트

새로운 구현이나 변경 사항이 아래 규칙을 만족하는지 확인합니다.

- [ ] 변기는 화면 하단 중앙에 위치하고 좌우로만 이동한다.
- [ ] 똥은 화면 상단에서 지속적으로 생성되어 아래로 떨어진다.
- [ ] 똥이 변기 영역에 도달하면 점수가 1 증가하고 오브젝트가 제거된다.
- [ ] 시간이 지날수록 낙하 속도(또는 생성 빈도)가 점진적으로 증가한다.
- [ ] 휴지는 똥과 함께 랜덤하게 섞여 떨어지며, 변기에 들어가도 점수에 영향이 없다.
- [ ] 똥을 놓치면(변기를 지나쳐 화면 밖으로 나가면) 게임이 종료된다.
- [ ] 종료 시 결과 화면에 총 성공 개수와 마무리 메시지를 표시한다.
- [ ] 최고 기록(하이스코어)을 확인하고 갱신할 수 있는 장치를 제공한다.

## 커밋/PR 가이드

- 변경 사항이 게임 규칙(PRD 내용)에 영향을 준다면 커밋 메시지나 PR 설명에 어떤 규칙이
  왜 바뀌었는지 명시합니다.
- 에셋(이미지 등)을 추가/교체할 때는 파일명과 용도를 README.md의 폴더 구성에 반영합니다.
