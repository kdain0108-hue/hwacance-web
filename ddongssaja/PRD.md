# 게임 PRD (Product Requirements Document)

## 1. 개요

| 항목 | 내용 |
|---|---|
| 게임명 (가칭) | 💩 똥 싸자 |
| 장르 | 캐주얼 아케이드 / 생존형 스코어 게임 |
| 플랫폼 | 모바일 (터치 기반) |
| 핵심 조작 | 드래그(또는 좌우 이동)로 변기를 움직여 떨어지는 똥 받기 |
| 세션 길이 | 짧은 플레이 타임, 반복 플레이 유도 |

## 2. 게임 목적

떨어지는 똥을 변기에 넣어 점수를 획득하는 단순하고 직관적인 캐주얼 게임을 제공한다.
시간이 지날수록 난이도(속도)가 상승하는 생존형 구조와, 휴지라는 방해 요소를 통해
짧은 시간 안에 순간적인 판단력과 집중력을 요구하는 재미를 준다.

## 3. 게임 방식

### 3.1 시작 화면
- 게임 진입 시 시작 화면에 **"똥 싸기 시작"** 버튼을 노출한다.
- 이용자가 버튼을 누르면 게임 플레이 화면으로 전환되며 낙하 및 카운트가 시작된다.

### 3.2 기본 플레이
- 화면 하단 중앙에 **변기**가 위치한다.
- 화면 상단에서 **똥**이 지속적으로 떨어진다.
- 이용자는 변기를 좌우로 드래그(또는 이동)하여 떨어지는 똥을 변기 안에 받는다.
- 똥이 변기 안에 들어가면 **점수 +1** 획득한다.

### 3.3 난이도 상승
- **성공(똥을 변기에 넣은) 개수가 10개 단위로 누적될 때마다** 다음 두 가지가 함께 상승한다.
  1. 똥이 떨어지는 **속도**
  2. 낙하물 중 **휴지가 섞여 등장하는 비중**
- 예: 0~9개 구간보다 10~19개 구간에서 낙하 속도가 더 빠르고 휴지 등장 비율도 더 높다.
- 구간이 올라갈수록 이용자에게 더 높은 반응 속도와 판단력을 요구한다.

### 3.4 방해 요소 (휴지)
- 게임 중간중간 **휴지**가 똥과 함께 화면 상단에서 떨어진다.
- 휴지는 **점수 획득 대상이 아니다.**
- 똥과 휴지가 시각적으로 섞여 등장하여 이용자의 순간적인 판단(똥인지 휴지인지 구분)을 요구한다.
- 휴지 등장 비중은 [3.3 난이도 상승](#33-난이도-상승) 규칙에 따라 10개 단위 구간마다 높아진다.

### 3.5 생명력 시스템
- 화면 **우측 상단에 하트 3개**로 생명력을 표시한다.
- 다음 두 경우에 생명력이 1 감소하며, 채워진 하트 하나가 빈 하트로 바뀐다.
  1. **휴지를 변기에 넣은 경우**
  2. **떨어지는 똥을 놓친 경우** (변기에 넣지 못하고 화면 밖으로 낙하)
- 생명력(하트)이 모두 소진되면 게임이 종료된다.

## 4. 게임 종료 조건

- **하트(생명력) 3개가 모두 소진되면** 게임이 종료된다.
  - 하트 소진 원인: 휴지를 받음, 또는 똥을 놓침 (각 1회당 하트 1개 감소)

## 5. 결과 화면

게임 종료 후 아래 정보를 결과 화면에 표시한다.

- **총 성공 개수**
  - 예: "총 37개의 똥을 변기에 넣었습니다!"
- **마무리 메시지**
  - 예: "오늘도 고생했어요. 🚽✨"

## 6. 핵심 게임 포인트

1. **직관적 조작**: 누구나 쉽게 이해할 수 있는 단순한 드래그 조작
2. **생존형 난이도**: 10개 단위로 속도와 휴지 비중이 함께 상승하는 스코어 어택 구조
3. **판단력 요구**: 휴지가 똥과 함께 등장하여 순간적인 구분과 집중력을 요구
4. **생명력 시스템**: 하트 3개로 약간의 실수 여유를 주면서도 긴장감을 유지
5. **동기 부여**: 자신의 최고 기록을 갱신하는 재미 제공 (최고 기록 저장/표시)
6. **짧은 세션**: 부담 없이 반복 플레이가 가능한 짧은 플레이 타임

## 7. 향후 논의가 필요한 사항 (Open Questions)

- 변기 이동 조작 방식: 드래그 vs 좌우 버튼 vs 기울기(자이로) 등 확정 필요
- 최고 기록 저장 방식: 로컬 저장 vs 서버/랭킹 연동 여부
- 난이도 곡선 구체적 수치: 10개 단위 구간별 속도 증가율(%) 및 휴지 등장 확률 구체값
- 하트 회복 여부: 플레이 도중 하트가 다시 채워지는 요소(아이템 등)가 있는지 여부
- 사운드/이펙트, 추가 아이템(예: 점수 2배 등) 도입 여부
