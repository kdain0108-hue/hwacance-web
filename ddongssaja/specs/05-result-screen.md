# SPEC 05. 결과 화면

상위 문서: [PRD.md](../PRD.md) · 관련: [SPEC 03 — 생명력 시스템](./03-life-system.md)

## 목적

게임 종료(하트 소진) 직후 이용자에게 이번 플레이의 성과를 요약해서 보여주고,
다시 플레이하고 싶은 동기를 준다.

## 1. 진입 조건

- 생명력(하트)이 0이 되어 게임이 종료되는 즉시 결과 화면으로 전환된다.
  (상세: [SPEC 03 — 생명력 시스템](./03-life-system.md))

## 2. 표시 정보

1. **총 성공 개수**
   - 예: "총 37개의 똥을 변기에 넣었습니다!"
   - 해당 플레이에서 획득한 점수(성공 횟수)를 그대로 사용한다.
2. **마무리 메시지**
   - 예: "오늘도 고생했어요. 🚽✨"
   - 고정 문구 또는 짧은 후보군 중 선택 (문구 확장 여부는 Open Question).

## 3. 화면 구성 (제안)

- 총 성공 개수를 가장 큰 시각적 비중으로 강조 표시한다.
- 마무리 메시지는 그 아래 보조적으로 노출한다.
- "다시 시작" 버튼을 제공하여 시작 화면 또는 즉시 재플레이로 이동할 수 있게 한다.
  (버튼 유무 및 동작은 Open Question — 최소한 시작 화면으로 복귀하는 경로는 있어야 함)

## 4. 다른 시스템과의 관계

- 결과 화면에 표시되는 점수는 [SPEC 01 — 코어 플레이](./01-core-gameplay.md)의 판정 규칙에 따라
  누적된 값과 동일해야 한다.
- 최고 기록(하이스코어) 갱신 여부를 이 화면에서 함께 안내할지는 Open Question.

## 5. 구현 체크리스트

- [ ] 게임 종료 시 결과 화면으로 전환하고 최종 점수를 전달한다.
- [ ] 총 성공 개수를 정확한 문구 형식으로 표시한다.
- [ ] 마무리 메시지를 표시한다.
- [ ] 결과 화면에서 다시 시작(또는 시작 화면으로 복귀)할 수 있는 경로를 제공한다.

## 6. Open Questions

- 최고 기록(하이스코어) 저장/표시를 이 화면에 포함할지, 포함한다면 로컬 저장인지
  서버/랭킹 연동인지 ([PRD.md](../PRD.md) 참고)
- "다시 시작" 버튼의 정확한 동작(시작 화면으로 이동 vs 즉시 재시작)
- 마무리 메시지를 여러 개 중 무작위로 노출할지 여부
