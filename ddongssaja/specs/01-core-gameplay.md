# SPEC 01. 코어 플레이 (시작 화면 & 기본 조작)

상위 문서: [PRD.md](../PRD.md)

## 목적

이 문서는 게임 시작부터 한 번의 "받기" 판정까지 이어지는 코어 루프의 세부 규칙을 정의한다.
난이도 상승, 생명력, 피드백 문구, 결과 화면은 각각의 SPEC 문서로 분리되어 있다.

## 1. 시작 화면

- 게임 진입 시 시작 화면에 **"똥 싸기 시작"** 버튼을 노출한다.
- 시작 화면은 전체 화면에 흩어진 텍스트가 아니라 하나의 팝업(모달) 카드 안에 표시된다.
  비주얼 스타일(카드 모양, 배경 스크림, 버튼 크기 등)은 [design.md 8장](../design.md#8-팝업모달-컴포넌트) 참고.
- 버튼을 누르기 전에는 낙하물이 생성되지 않고, 점수/타이머/난이도가 진행되지 않는다.
- 버튼을 누르면:
  1. 점수를 0으로 초기화한다.
  2. 생명력(하트)을 3개(가득 참)로 초기화한다. (상세: [SPEC 03](./03-life-system.md))
  3. 난이도 구간을 0단계(최초 구간)로 초기화한다. (상세: [SPEC 02](./02-difficulty-progression.md))
  4. 낙하물 생성을 시작한다.

## 2. 변기 (플레이어 오브젝트)

- 화면 하단 중앙에 위치한다.
- 좌우로만 이동하며, 이용자의 드래그(또는 이동 입력)를 따라간다.
- 화면 좌우 경계를 벗어나지 않도록 이동 범위를 제한한다.

## 3. 낙하물 (똥 / 휴지)

- 화면 상단에서 낙하물이 지속적으로 생성되어 아래로 떨어진다.
- 낙하물의 종류는 두 가지다.
  - **똥**: 득점 대상
  - **휴지**: 방해 요소, 득점 대상 아님 (상세: [SPEC 03](./03-life-system.md))
- 낙하물은 화면 내 임의의 가로 위치에서 생성된다.
- 낙하 속도와 휴지 등장 비중은 고정값이 아니며, 난이도 구간에 따라 변한다. (상세: [SPEC 02](./02-difficulty-progression.md))

## 4. 판정 규칙

| 상황 | 결과 |
|---|---|
| 똥이 변기 영역에 도달 | 점수 +1, 낙하물 제거, 칭찬 피드백 문구 표시 ([SPEC 04](./04-feedback-messages.md)) |
| 휴지가 변기 영역에 도달 | 점수 변화 없음, 생명력 -1 ([SPEC 03](./03-life-system.md)) |
| 똥이 변기를 지나쳐 화면 밖으로 낙하 | 생명력 -1 ([SPEC 03](./03-life-system.md)) |
| 휴지가 변기를 지나쳐 화면 밖으로 낙하 | 아무 일도 일어나지 않음 (페널티 없음) |

## 5. 판정 우선순위 및 엣지 케이스

- 한 프레임에 여러 낙하물이 동시에 변기 영역에 도달할 경우, 각 낙하물을 개별적으로 판정한다
  (동시 판정으로 하트가 한 번에 2 이상 감소할 수 있음).
- 낙하물과 변기의 충돌 판정 영역(히트박스) 크기는 구현 단계에서 확정한다 (Open Question).
