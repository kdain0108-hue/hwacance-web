# 💩 똥 싸자

떨어지는 똥을 변기로 받아 점수를 쌓는 짧고 중독성 있는 캐주얼 아케이드 게임입니다.
자세한 기획 내용은 [PRD.md](./PRD.md)를 참고하세요.

## 한 줄 소개

화면 상단에서 떨어지는 똥을 변기로 이동시켜 받아내고, 시간이 지날수록 빨라지는 속도와
방해 요소(휴지)를 뚫고 최고 기록에 도전하는 게임입니다.

## 핵심 게임 플레이

- **시작**: "똥 싸기 시작" 버튼을 눌러 게임을 시작합니다.
- **조작**: 화면 하단의 변기를 드래그(좌우 이동)해서 조작합니다.
- **목표**: 위에서 떨어지는 똥을 변기 안에 받아 점수를 획득합니다.
- **난이도**: 성공 개수가 10개 단위로 쌓일 때마다 낙하 속도와 휴지 등장 비중이 함께 높아집니다.
- **방해 요소**: 똥과 함께 휴지가 섞여 떨어집니다. 휴지는 점수 대상이 아니며 순간적인 구분을 요구합니다.
- **생명력**: 우측 상단에 하트 3개로 표시됩니다. 휴지를 받거나 똥을 놓치면 하트가 하나씩 빈 하트로 바뀝니다.
- **종료 조건**: 하트 3개가 모두 소진되면 게임이 종료됩니다.
- **결과 화면**: 총 성공 개수와 마무리 메시지("오늘도 고생했어요. 🚽✨")를 보여줍니다.
