# SPEC 04. 성공 피드백 문구 (칭찬 팝업)

상위 문서: [PRD.md](../PRD.md) · 관련: [SPEC 01 — 코어 플레이](./01-core-gameplay.md)

## 목적

똥을 변기에 성공적으로 넣었을 때, 짧고 가벼운 칭찬 문구를 변기 옆에 잠깐 띄워
성취감과 손맛(피드백감)을 강화한다.

## 1. 트리거 조건

- **똥이 변기 영역에 도달해 점수가 +1 되는 순간** 트리거된다.
- 휴지를 받았을 때, 똥을 놓쳤을 때는 트리거되지 않는다 (칭찬 문구는 성공 시에만 노출).

## 2. 표시 방식

- 위치: **변기 옆(측면)**, 작고 눈에 거슬리지 않는 크기.
- 형태: 짧은 한 줄 텍스트. 말풍선/토스트 등 가벼운 스타일을 권장한다.
- 길이: 매우 짧게 노출(예: 0.5~1초 내외)되고 자동으로 사라진다 — 정확한 지속 시간은
  구현 시 확정 (Open Question).
- 다음 성공 판정이 이전 문구가 아직 사라지기 전에 발생하면, 이전 문구를 즉시 교체하거나
  중첩 없이 최신 문구로 갱신한다 (동시에 여러 문구가 쌓이지 않도록 한다).

## 3. 문구 목록

아래 10개 문구 중 하나를 매 성공 시 노출한다.

1. 넌 참 잘했어.
2. 오늘도 수고했어.
3. 완벽한 골인이야!
4. 명중!
5. 역시 프로야.
6. 깔끔했다.
7. 이게 바로 실력.
8. 천재 아니야?
9. 감각이 살아있네.
10. 오늘 폼 미쳤다.

## 4. 선택 로직

- 매 성공 시 위 목록 중 **하나를 무작위로 선택**하여 표시한다.
- 바로 직전에 표시된 문구와 동일한 문구가 연속으로 나오지 않도록 하는 것을 권장한다
  (완전 배제까지는 필수는 아니며, 반복감을 줄이는 목적).

## 5. 다른 시스템과의 관계

- 이 문구는 순수 UI 피드백이며, 점수/생명력/난이도 로직에 어떤 영향도 주지 않는다.
- 난이도 구간이 올라가도 문구 목록이나 노출 로직은 동일하게 유지된다 (구간별 별도 문구 세트는
  현재 범위 밖).

## 6. 구현 체크리스트

- [ ] 똥 성공 판정과 문구 노출 로직을 연결한다 (성공 시에만, 매번).
- [ ] 문구는 10개 목록에서 무작위로 선택한다.
- [ ] 문구는 변기 옆에 작게, 짧은 시간 동안만 노출되고 자동으로 사라진다.
- [ ] 연속된 성공 시 문구가 화면에 겹쳐 쌓이지 않도록 처리한다.
- [ ] 문구 목록은 하드코딩보다 별도 데이터(배열/리소스 파일)로 관리하여 추후 문구 추가/수정이
      쉽도록 한다.

## 7. Open Questions

- 정확한 노출/페이드아웃 지속 시간(초)
- 폰트 크기, 색상 등 구체적인 비주얼 스타일
- 문구 세트를 추후 확장(예: 난이도 구간별 다른 문구, 콤보 전용 문구)할지 여부
