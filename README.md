# 화캉스

> 시간은 화캉스가 챙기고, 사용자는 잠깐 마음을 놓습니다.

화캉스는 직장인이 화장실에서 보내는 짧은 휴식을 돕는 모바일 웹입니다.
정한 시간 안에 돌아갈 수 있도록 타이머를 제공하고,
유쾌한 창작 문장 따라쓰기와 잔잔한 ASMR로 짧은 주의 전환을 돕습니다.

## 현재 상태

이 저장소는 MVP 구현 전 제품 문서가 정리된 상태입니다.
제품 범위와 상세 기능 사양이 승인되면 구현 계획과 애플리케이션 코드가 추가됩니다.

## MVP 핵심 기능

- `5분`, `10분`, `15분` 프리셋과 1~60분 직접 입력 타이머
- 닫히고 열리는 픽셀 변기와 아이폰 타이머형 원형 진행 표시
- `부처되기`에서 유쾌한 창작 위로 문장 100개 따라쓰기
- 완료한 필사 목록과 완료 화면 PNG 저장
- `눈치껏 쉬자`에서 오늘의 화장쉼 시각 기록과 경과 시간 안내
- 모든 주요 화면 오른쪽 상단의 전역 ASMR ON/OFF
- 로그인이나 계정 없이 즉시 사용할 수 있는 모바일 웹

## 중요한 제품 제약

화캉스 MVP는 설치가 필요 없는 일반 모바일 웹입니다.

- 화면이 켜져 있고 페이지가 활성 상태일 때 타이머 완료를 지원합니다.
- 화면 잠금이나 백그라운드에서는 정시 알림·소리·진동을 보장하지 않습니다.
- 휴대폰 전원이 완전히 꺼지면 웹에서 진동이나 알림을 실행할 수 없습니다.
- 진동은 지원 브라우저에서만 사용하는 보조 수단입니다.
- ASMR은 사용자가 직접 ON을 누른 뒤에만 재생됩니다.

## 제품 화면 구조

```text
화캉스
├─ 상단 헤더
│  ├─ 현재 화면 제목
│  └─ ASMR ON/OFF
├─ 콘텐츠
│  ├─ 눈치껏 쉬자
│  ├─ 타이머
│  └─ 부처되기
└─ 하단 고정 내비게이션
   ├─ 눈치껏 쉬자
   ├─ 타이머
   └─ 부처되기
```

첫 진입 화면은 `타이머`입니다.
하단 탭으로 화면을 바꿔도 진행 중인 타이머와 ASMR 상태는 유지됩니다.

## 콘텐츠 원칙

`부처되기`는 유쾌한 창작 문장을 따라 쓰는 제품 속 코너입니다.
실제 불교 경전이나 역사적 인물의 발언을 인용하지 않습니다.

- 모든 문장은 화캉스의 창작 위로 문장입니다.
- 출시 콘텐츠는 100개이며 사람이 중복·어조·안전성을 검수합니다.
- 화면에 창작 문장이라는 사실을 분명하게 표시합니다.
- 공격적 욕설, 차별, 자해·폭력 조장, 특정 개인·회사 비방은 허용하지 않습니다.

## 시각 방향

- 메인 컬러는 흰색과 파란색 `#6485F6`입니다.
- 타이머의 중심에는 닫힘·열림 상태를 가진 픽셀 변기를 사용합니다.
- 실행 중에는 열린 변기 주변에서 원형 진행률이 감소합니다.
- 유머는 과한 장식보다 픽셀 그래픽과 문구로 표현합니다.

## MVP에서 하지 않는 것

- 네이티브 iOS·Android 앱
- 설치 가능한 PWA와 오프라인 실행
- 웹 푸시 또는 잠금 화면 정시 알림 보장
- 회원가입, 로그인, 서버 동기화
- 복수 ASMR 음원 및 재생 목록
- AI 실시간 문장 생성
- 똥 넣기 게임

## 구현 전 확인할 문서

작업자는 먼저 [agent.md](./agent.md)를 읽고,
변경 대상 기능의 상세 사양을 확인해야 합니다.
메인 PRD와 상세 사양이 충돌하면 임의로 해석하지 말고 문서를 함께 수정합니다.

## 문서 변경 원칙

- 제품 방향 변경은 `PRD.md`에 반영합니다.
- 기능 동작 변경은 해당 `spec/` 문서에 반영합니다.
- 공통 UI, 접근성, 브라우저 정책은 `spec/platform-and-ux.md`에 반영합니다.
- 문서 링크와 요구사항 ID가 깨지지 않았는지 변경 후 확인합니다.
- 확정되지 않은 기능을 구현 범위처럼 문서에 추가하지 않습니다.
