## 1. 목적

사용자가 오늘 하루 화장쉼한 시각을 스스로 기록하고,
마지막 화장쉼으로부터 얼마나 지났는지를 보고
다음 화장쉼 타이밍을 가볍게 가늠하도록 돕는다.

## 2. 범위

MVP는 다음만 제공한다.

- 오늘 하루 동안의 화장쉼 기록(시:분)
- 마지막 기록 이후 경과 시간 표시
- 경과 시간에 따른 3단계 안내 문구
- 기기 내 저장과 자정 기준 초기화

서버 동기화, 통계, 알림, 다른 사람과의 공유는 제공하지 않는다.

## 3. 위치와 진입

| ID | 요구사항 |
| --- | --- |
| BRK-01 | 하단 내비게이션 가장 왼쪽에 `눈치껏 쉬자` 탭을 둔다. |
| BRK-02 | 탭 순서는 `눈치껏 쉬자`, `타이머`, `부처되기`다. |
| BRK-03 | 기본 진입 화면은 여전히 타이머이며 이 탭은 선택했을 때만 보인다. |
| BRK-04 | 화면 상단에 헤더 제목 `눈치껏 쉬자`와 ASMR 토글을 동일하게 표시한다. |

## 4. 데이터 모델

기록 항목은 `{ id, recordedAt }`이며 `recordedAt`은 절대 시각의 epoch ms다.

| ID | 요구사항 |
| --- | --- |
| BRK-05 | 기록은 기기의 오늘 날짜 기준으로 관리한다. |
| BRK-06 | 자정이 지나면 이전 날짜의 기록은 목록에서 제외한다. |
| BRK-07 | 기록과 마지막 기록 시각은 기기에 저장하고 서버로 전송하지 않는다. |
| BRK-08 | 저장값이 손상되면 오늘 기록이 없는 상태로 복구한다. |

## 5. 경과 시간 계산

원본 공식은 다음과 같다.

```text
elapsedMs = max(0, now - lastRecordedAt)
```

| ID | 요구사항 |
| --- | --- |
| BRK-09 | 경과 시간은 반복 호출 누적이 아니라 현재 시각과 마지막 기록 시각의 차이로 계산한다. |
| BRK-10 | 화면은 약 30초~1분 간격으로 갱신하되 매번 현재 시각으로 다시 계산한다. |
| BRK-11 | 페이지가 다시 보이면 즉시 경과 시간을 다시 계산한다. |
| BRK-12 | 오늘 기록이 없으면 경과 시간 대신 첫 기록 안내를 표시한다. |

## 6. 안내 문구

| 경과 시간 | 문구 |
| --- | --- |
| 30분 미만 | `아직은 눈치보여요` |
| 30분 이상 ~ 60분 미만 | `조금 더 버텨보는 걸 추천` |
| 60분 이상 | `이제는 마음껏 화장쉼하세요` |

| ID | 요구사항 |
| --- | --- |
| BRK-13 | 경과 시간 구간에 맞는 안내 문구를 화면 상단에 표시한다. |
| BRK-14 | 문구와 함께 경과 시간을 `N시간 N분` 또는 `N분` 텍스트로 표시한다. |
| BRK-15 | 오늘 첫 기록 전에는 `오늘의 첫 화장쉼을 기록해보세요`를 표시한다. |
| BRK-16 | 안내 문구는 색상뿐 아니라 문구 자체로 상태를 전달한다. |

## 7. 기록하기

| ID | 요구사항 |
| --- | --- |
| BRK-17 | `화장쉼 기록하기` 버튼을 누르면 현재 시각을 새 기록으로 추가한다. |
| BRK-18 | 기록 직후 경과 시간 표시를 0분 기준으로 즉시 갱신한다. |
| BRK-19 | 300ms 이내의 중복 탭은 하나의 기록으로만 처리한다. |
| BRK-20 | 기록 버튼의 터치 영역은 최소 44×44px다. |

## 8. 오늘의 기록 목록

| ID | 요구사항 |
| --- | --- |
| BRK-21 | 오늘 기록한 화장쉼 시각을 `HH:MM` 형식으로 목록에 표시한다. |
| BRK-22 | 최근 기록을 목록 위에 표시한다. |
| BRK-23 | 오늘 기록이 없으면 `오늘 기록된 화장쉼이 없어요`를 표시한다. |
| BRK-24 | 목록 항목 삭제나 수정 기능은 MVP에서 제공하지 않는다. |

## 9. 오류와 예외

| 상황 | 동작 |
| --- | --- |
| 기기 저장 실패 | 현재 세션 기록만 유지하고 기록 흐름은 계속 |
| 화면을 켜둔 채 자정을 넘김 | 다음 갱신 주기에 새 날짜 기준으로 전환 |
| 기기 시각 변경 | 새 현재 시각과 저장된 기록 시각으로 다시 계산 |
| 저장값 형식 손상 | 오늘 기록 없음 상태로 복구 |

## 10. 접근성

- 경과 시간과 안내 문구를 스크린 리더가 함께 읽을 수 있게 한다.
- 안내 문구 변화를 과도하게 반복 공지하지 않는다.
- 기록 버튼에 `화장쉼 기록하기` 접근성 이름을 제공한다.
- 색상만으로 안내 단계를 구분하지 않는다.

## 11. 개인정보

- 화장쉼 기록은 기기에만 저장하고 서버나 분석 도구로 전송하지 않는다.
- 이름, 위치 등 개인 식별 정보와 함께 저장하지 않는다.
- 다른 사용자와 기록을 공유하는 기능을 제공하지 않는다.

## 12. 검수 기준

- [ ] 하단 내비게이션 왼쪽에 `눈치껏 쉬자` 탭이 보인다.
- [ ] 탭 순서가 `눈치껏 쉬자`, `타이머`, `부처되기`다.
- [ ] 오늘 첫 진입 시 `오늘의 첫 화장쉼을 기록해보세요`가 보인다.
- [ ] 기록 후 경과 시간이 0분 기준으로 갱신된다.
- [ ] 30분 미만, 30~60분, 60분 이상 구간별 문구가 정확히 전환된다.
- [ ] 오늘 기록 목록이 최신순으로 `HH:MM` 형식으로 보인다.
- [ ] 자정이 지나면 전날 기록이 더 이상 표시되지 않는다.
- [ ] 저장 실패 환경에서도 현재 세션 기록과 문구가 동작한다.
- [ ] 색상 없이도 문구만으로 상태를 이해할 수 있다.
