# 공통 플랫폼 및 UX 사양

| 항목 | 내용 |
| --- | --- |
| 문서 ID | SPEC-PLATFORM |
| 버전 | 1.0 |
| 대상 | 일반 모바일 웹 MVP |
| 상위 문서 | [PRD.md](../PRD.md) |

## 1. 목적

이 문서는 타이머, 부처되기, ASMR에 공통으로 적용되는
플랫폼 지원 범위, 화면 구조, 전역 상태, 반응형, 접근성, 품질 기준을 정의한다.

기능 내부 동작은 각 기능 사양을 따른다.

## 2. 지원 범위

### 2.1 공식 지원

- 최신 모바일 브라우저의 세로 화면
- 320~430px 너비의 스마트폰
- 화면이 켜져 있고 화캉스 페이지가 활성화된 상태
- 터치 입력과 모바일 가상 키보드
- 로그인 없는 단일 기기 사용

### 2.2 최선 지원

- 태블릿과 데스크톱 브라우저
- 브라우저 탭 전환 후 상태 복원
- 지원 브라우저의 진동과 화면 깨우기
- 브라우저가 허용하는 범위의 백그라운드 오디오

### 2.3 지원하지 않는 약속

- 화면 잠금 상태의 정시 알림
- 다른 앱이 전면에 있을 때 소리나 진동
- 전원이 완전히 꺼진 기기의 알림
- 오프라인 최초 접속
- PWA 설치와 웹 푸시

## 3. 정보 구조

```text
화캉스
├─ 공통 헤더
│  ├─ 현재 화면 제목
│  └─ ASMR ON/OFF
├─ 화면 콘텐츠
│  ├─ 타이머
│  └─ 부처되기
└─ 하단 고정 내비게이션
   ├─ 타이머
   └─ 부처되기
```

## 4. 내비게이션

| ID | 요구사항 |
| --- | --- |
| PLT-01 | 첫 방문과 일반 재방문의 기본 화면은 타이머다. |
| PLT-02 | 하단에 `타이머`, `부처되기` 두 탭을 고정한다. |
| PLT-03 | 현재 탭은 색상, 형태, 접근성 상태로 구분한다. |
| PLT-04 | 탭 전환으로 타이머와 ASMR 전역 상태를 초기화하지 않는다. |
| PLT-05 | 브라우저 뒤로 가기는 사이트 내부 이동 이력과 일관되게 동작한다. |
| PLT-06 | 하단 내비게이션은 운영체제 안전 영역을 침범하지 않는다. |

## 5. 공통 헤더

| ID | 요구사항 |
| --- | --- |
| PLT-07 | 헤더 왼쪽 또는 중앙에 현재 화면 제목을 표시한다. |
| PLT-08 | 헤더 오른쪽에 ASMR ON/OFF를 표시한다. |
| PLT-09 | ASMR 컨트롤은 두 화면에서 같은 위치와 형태를 사용한다. |
| PLT-10 | 헤더는 콘텐츠를 과도하게 가리지 않는 높이로 유지한다. |

## 6. 레이아웃

| ID | 요구사항 |
| --- | --- |
| PLT-11 | 320px 너비에서 가로 스크롤이 생기지 않는다. |
| PLT-12 | 핵심 콘텐츠 최대 너비는 480px다. |
| PLT-13 | 480px보다 넓은 화면에서는 콘텐츠를 중앙에 배치한다. |
| PLT-14 | 주요 행동은 한 손 엄지로 누르기 쉬운 위치에 둔다. |
| PLT-15 | 모바일 키보드가 열린 상태에서도 입력과 현재 문장을 확인할 수 있다. |
| PLT-16 | 고정 헤더와 하단 탭이 본문 마지막 콘텐츠를 가리지 않는다. |

## 7. 시각 방향

- 메인 컬러는 흰색 `#FFFFFF`과 파란색 `#6485F6`이다.
- 흰색을 주 배경으로, `#6485F6`을 주요 버튼·선택·진행 상태에 사용한다.
- 작은 본문은 가독성을 위해 짙은 회색을 사용한다.
- `#6485F6`은 흰색 위의 작은 본문 색으로 사용하지 않는다.
- 화면마다 가장 중요한 요소 하나만 강하게 강조한다.
- 장식보다 시간과 문장의 가독성을 우선한다.
- 유쾌함은 픽셀 그래픽, 문구, 필사 완료 화면으로 표현한다.
- 원형 타이머는 타이머 화면의 가장 큰 시각 요소다.

## 8. 전역 상태

전역에서 공유하는 상태는 다음과 같다.

```text
activeScreen
timerStatus
timerDurationMs
timerEndAt
timerPausedRemainingMs
asmrStatus
currentMessageId
seenMessageIds
completedMessageRecords
```

| ID | 요구사항 |
| --- | --- |
| PLT-17 | 타이머 상태와 ASMR 상태는 화면보다 상위에서 관리한다. |
| PLT-18 | 화면 전환으로 오디오 인스턴스를 새로 만들지 않는다. |
| PLT-19 | 저장 가능한 상태와 일시 상태를 구분한다. |
| PLT-20 | 저장소 오류가 핵심 화면 전체를 중단시키지 않는다. |

## 9. 기기 내 저장

저장 허용:

- 타이머 전체 시간
- 종료 예정 시각
- 일시정지 잔여 시간
- 현재 문장 ID
- 이미 본 문장 ID 목록
- 완료한 문장 ID와 완료 시각 목록

저장 금지:

- 사용자가 따라 쓴 입력 문자열
- 이름, 이메일, 회사, 위치
- 마이크 입력과 주변 소리
- 개인별 ASMR 사용 기록
- 생성한 필사 이미지 원본

## 10. 공통 오류 처리

| 상황 | 동작 |
| --- | --- |
| 로컬 저장소 사용 불가 | 현재 탭에서 계속 동작하고 새로고침 복원만 생략 |
| 진동 미지원 | 화면 완료 상태와 가능한 경우 완료음 사용 |
| 화면 깨우기 미지원 | 타이머는 계속하고 화면 유지 안내 제공 |
| 네트워크 단절 | 이미 로드된 타이머는 유지, 미로드 자산 실패 안내 |
| 예상하지 못한 오류 | 핵심 상태 손상을 피하고 새로고침으로 기본 화면 복구 |

## 11. 접근성

| ID | 요구사항 |
| --- | --- |
| PLT-21 | 모든 터치 영역은 최소 44×44px다. |
| PLT-22 | 본문과 배경은 WCAG AA 수준 명도 대비를 만족한다. |
| PLT-23 | 색상만으로 선택, 오류, 진행 상태를 전달하지 않는다. |
| PLT-24 | 모든 조작 요소에 의미 있는 접근성 이름을 제공한다. |
| PLT-25 | 키보드 포커스 표시를 제거하지 않는다. |
| PLT-26 | 모션 감소 설정에서 불필요한 애니메이션을 최소화한다. |
| PLT-27 | 소리가 없어도 완료와 오류를 화면으로 이해할 수 있다. |
| PLT-28 | 원형 진행률에 대응하는 남은 시간 텍스트를 제공한다. |

## 12. 성능

| ID | 요구사항 |
| --- | --- |
| PLT-29 | 일반적인 4G 환경에서 주요 콘텐츠 표시를 2.5초 이내로 목표한다. |
| PLT-30 | ASMR 전체 파일은 사용자가 ON을 누르기 전에 강제 다운로드하지 않는다. |
| PLT-31 | 핵심 버튼의 레이아웃 이동으로 오탭이 발생하지 않게 한다. |
| PLT-32 | 화면 갱신은 사용자 입력을 막지 않아야 한다. |

## 13. 브라우저 생명주기

- 페이지가 숨겨질 때 현재 저장 가능 상태를 기록한다.
- 페이지가 다시 보이면 현재 시각으로 타이머를 재계산한다.
- 오디오의 실제 재생 여부와 UI 상태를 동기화한다.
- 지원 기능 여부를 최초 실행 시 탐지한다.
- 지원되지 않는 API 호출은 예외 없이 건너뛸 수 있어야 한다.

## 14. 개인정보

- MVP는 서버 데이터베이스와 계정을 사용하지 않는다.
- 행동 분석을 위해 입력 문장이나 개인 식별 정보를 전송하지 않는다.
- 브라우저 저장소를 비우면 기기 내 상태가 초기화될 수 있음을 안내한다.
- 새로운 외부 분석 도구 도입은 별도 제품 결정으로 취급한다.

## 15. 검수 기준

- [ ] 320px, 390px, 430px 화면에서 핵심 UI가 잘리지 않는다.
- [ ] 두 화면에서 ASMR 컨트롤 위치와 상태가 동일하다.
- [ ] 탭 전환 후 타이머 상태가 유지된다.
- [ ] 탭 전환 후 ASMR 상태와 실제 재생 상태가 일치한다.
- [ ] 메인 버튼과 진행 상태에 `#6485F6`이 일관되게 적용된다.
- [ ] 완료 문장 ID·시각만 기기에 저장되고 작성 입력은 저장되지 않는다.
- [ ] 키보드만으로 모든 주요 기능을 조작할 수 있다.
- [ ] 스크린 리더가 현재 탭과 ASMR 상태를 읽을 수 있다.
- [ ] 모션 감소 환경에서 필사 완료 효과가 과도하게 움직이지 않는다.
- [ ] 로컬 저장소를 차단해도 현재 세션의 타이머가 동작한다.
- [ ] 지원하지 않는 진동 API 때문에 오류 화면이 발생하지 않는다.
- [ ] 개인정보에 해당하는 입력값이 네트워크로 전송되지 않는다.
