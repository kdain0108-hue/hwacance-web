## 1. 목적

화캉스 MVP의 색상, 타이포그래피, 배경 패턴, 화면별 시각 구성 규칙을 정의한다.
기능 동작은 각 기능 사양이 소유하며, 이 문서는 시각적 표현만 소유한다.

## 2. 범위

- 색상 토큰
- 타이포그래피(픽셀 폰트 적용 범위)
- 배경 패턴(모눈 그리드)
- 타이머, 눈치껏 쉬자, 부처되기 화면별 시각 구성
- 공용 픽셀 컴포넌트(버튼, 말풍선, 변기 그래픽, 브랜드 워드마크)

## 3. 색상

| ID | 요구사항 |
| --- | --- |
| DSN-01 | 메인 컬러는 흰색 `#FFFFFF`과 파란색 `#6485F6`이다. |
| DSN-02 | 보조 파란색 `#4C6BDB`은 강조 텍스트와 진행 상태에 사용한다. |
| DSN-03 | 타이머·부처되기 배경 그리드는 흰색 `#FFFFFF` 바탕에 파란색 선 `#BCD3FF`을 사용한다. |
| DSN-04 | 눈치껏 쉬자의 `아직은 눈치 봐야 해요` 문구는 `#6485F6`으로 표시한다. |

## 4. 타이포그래피

| ID | 요구사항 |
| --- | --- |
| DSN-05 | 앱 전체 기본 서체는 `Mona12`(픽셀 서체)다. |
| DSN-06 | 한글이 포함된 화면이므로 한글 전용 커팅인 `Mona12TextKR`을 임베드해 사용한다. |
| DSN-07 | `Mona12`가 렌더링하지 못하는 문자는 시스템 한글 서체(`Apple SD Gothic Neo`, `맑은 고딕`)로 대체한다. |
| DSN-08 | 자간과 줄 간격은 픽셀 서체의 각진 형태를 해치지 않는 범위에서 최소로 조정한다. |

### 4.1 서체 출처와 라이선스

- 서체 파일 출처: `C:\Users\user\Desktop\MY\활동 아카이빙\PPT\FONT`(사용자 로컬 보관 폰트)
- 웹 배포용 `woff2`를 base64로 인코딩해 `prototype_V1.0.html`에 직접 포함했다(외부 CDN 의존 없음).
- 이 폰트의 재배포·임베드 라이선스는 저장소 밖에서 확인되지 않았다.
  실 서비스로 출시하기 전 [asmr.md](./asmr.md)의 AUD-25/26과 동일한 기준으로
  라이선스 증빙을 운영 기록에 확보해야 한다.

## 5. 배경 패턴 — 모눈 그리드

| ID | 요구사항 |
| --- | --- |
| DSN-09 | 타이머, 부처되기 화면은 흰 바탕에 파란 선 모눈 그리드를 배경으로 사용한다. |
| DSN-10 | 눈치껏 쉬자 화면은 흰 배경을 유지하고 그리드를 사용하지 않는다. |

## 6. 공용 픽셀 컴포넌트

### 6.1 브랜드 워드마크

| ID | 요구사항 |
| --- | --- |
| DSN-13 | 타이머 화면 헤더 좌측에는 화면 제목 대신 브랜드명 `화캉스`를 표시한다. |
| DSN-14 | 브랜드 워드마크는 흰색 글자에 파란색 `#4C6BDB` 테두리를 적용한다. |
| DSN-14a | 워드마크는 CSS 텍스트 외곽선이 아니라 SVG `<text>`의 `stroke`+`paint-order`로 그려 외곽선이 끊기지 않게 한다. |
| DSN-15 | 타이머 외 화면 헤더는 기존처럼 현재 화면 제목을 그대로 표시한다. |

### 6.2 픽셀 버튼

| ID | 요구사항 |
| --- | --- |
| DSN-16 | 주요 버튼(`화장쉼 시작하기`, `쉬기 시작`, `체크아웃`, `화장쉼 기록하기` 등)은 알약형 테두리에 위쪽 밝은 하이라이트, 아래쪽 진한 그림자를 안쪽 음영으로 넣은 픽셀 게임 버튼 스타일을 사용한다. |
| DSN-16a | 버튼 좌상단에는 작은 흰색 광택 표시를 둔다. |
| DSN-17 | 픽셀 버튼은 눌림 상태에서 안쪽 음영이 줄고 버튼이 아래로 살짝 이동한다. |
| DSN-18 | 픽셀 버튼도 다른 버튼과 동일하게 최소 44×44px 터치 영역을 만족한다. |

### 6.3 픽셀 변기

| ID | 요구사항 |
| --- | --- |
| DSN-19 | 변기는 위에서 본 타원형 좌변(뚜껑)과 옆에 붙은 사각 물탱크, 아래의 넓은 받침으로 구성된 픽셀 그래픽이다. |
| DSN-20 | 물탱크에는 파란색 강조 픽셀(물내림 버튼)을 둔다. |
| DSN-21 | 닫힘 상태는 타원이 흰색으로 채워진 형태, 열림 상태는 타원 안에 파란색 고리와 진한 파란색 구멍이 겹겹이 보이는 형태다. |
| DSN-21a | 변기는 진한 남색 대신 파란색 계열 외곽선(`#4C6BDB`)과 흰색·연파랑 채움만 사용한다. |
| DSN-22 | 부처되기 화면 하단에는 작은 크기의 닫힘 상태 변기를 장식으로 사용한다. |

> 참고: 사용자가 공유한 레퍼런스 사진을 참고해 다시 그린 픽셀 그래픽이다.
> 좌표 기반 타원 근사로 만든 손그림 해석이라 사진과 정확히 일치하지는 않는다.

### 6.4 픽셀 말풍선

| ID | 요구사항 |
| --- | --- |
| DSN-23 | 말풍선은 흰 배경, 3px 각진 테두리, 아래를 향한 삼각형 꼬리로 구성한다. |
| DSN-24 | 부처되기 하단 변기 위 말풍선에는 `오늘도 쉽지 않다.`를 고정 문구로 표시한다. |

## 7. 화면별 시각 구성

### 7.1 타이머

- 모든 상태(idle·setting·running·paused·completed)의 콘텐츠는 헤더와 하단 내비게이션 사이 영역에서 수직 중앙 정렬한다.
- idle·setting 상태에서는 원형 진행률 없이 `화장쉼 시작하기` 픽셀 버튼과 닫힌 변기를 세로로 묶어 중앙에 배치한다.
- running·paused·completed 상태는 기존처럼 원형 진행률과 변기를 함께 중앙에 배치한다([timer.md](./timer.md) 소유).
- 배경은 모눈 그리드([5장](#5-배경-패턴--모눈-그리드)).

### 7.2 눈치껏 쉬자

- 전체 화면 서체는 `Mona12`([4장](#4-타이포그래피))다.
- 배경은 흰색을 유지한다(그리드 미사용).
- 경과 시간 안내 문구 중 `아직은 눈치 봐야 해요`는 파란색이다([3장](#3-색상)).
- 그 외 상태 모델, 기록 로직은 [break-tracker.md](./break-tracker.md)가 소유한다.

### 7.3 부처되기

| ID | 요구사항 |
| --- | --- |
| DSN-25 | 오늘의 문장 화면 상단 중앙에 오늘 날짜와 시각을 `YYYY.MM.DD (요일) HH:MM` 형식으로 표시한다. |
| DSN-26 | 날짜 아래 중앙에 `오늘의 부처되기 문장` 라벨을 표시한다. |
| DSN-27 | 문장 표시 영역은 배경색과 테두리가 없는 순수 텍스트로 표시한다. |
| DSN-28 | 문장 표시 영역을 탭하면 그 자리에서 바로 입력을 시작할 수 있다(별도 입력 상자 없음). |
| DSN-29 | 실제 입력 요소는 화면에서 보이지 않게 처리하되 접근성 이름은 유지한다. |
| DSN-30 | 입력 요소가 포커스를 받으면 문장 표시 영역에 포커스 링을 표시한다. |
| DSN-31 | 화면 하단에는 [6.2절](#63-픽셀-변기) 변기와 [6.4절](#64-픽셀-말풍선) 말풍선을 배치한다. |
| DSN-32 | 완료 목록에서 문장을 선택하면 다시 입력하지 않고 해당 문장의 필사 완료 화면을 바로 보여준다. |
| DSN-33 | 배경은 모눈 그리드([5장](#5-배경-패턴--모눈-그리드))이며 완료·목록 화면에도 동일하게 적용한다. |

문장 판정, 완료 목록 데이터, 이미지 저장 로직은 [quote-writing.md](./quote-writing.md)가 소유한다.
이 문서는 위 요구사항의 시각적 표현만 소유하며, 문장 판정 방식이 바뀌면
quote-writing.md를 함께 수정한다.

## 8. 접근성

- 픽셀 서체가 특정 글자를 지원하지 않아도 대체 서체로 자동 전환되어 텍스트 손실이 없어야 한다.
- 숨겨진 입력 요소는 `opacity:0`으로 시각적으로만 숨기고 `display:none`을 사용하지 않아 포커스와 모바일 키보드 동작을 유지한다.
- 문장 표시 영역은 `aria-hidden`으로 보조기기 중복 낭독을 막고, 실제 입력 요소에 접근성 이름을 둔다.
- 모눈 그리드는 본문 대비에 영향을 주지 않는 옅은 색만 사용한다.
- 브랜드 워드마크의 테두리 스타일은 장식이며 화면 제목 정보 손실 없이 대체 텍스트를 유지한다.

## 9. 검수 기준

- [ ] 메인 컬러와 강조색이 색상 토큰과 일치한다.
- [ ] 한글 텍스트가 깨지거나 대체 서체로 보이지 않고 `Mona12`로 표시된다.
- [ ] 타이머·부처되기 화면에 흰 바탕·파란 선 모눈 그리드 배경이 보인다.
- [ ] 눈치껏 쉬자 화면은 그리드 없이 흰 배경이며 전체가 `Mona12`로 보인다.
- [ ] `아직은 눈치 봐야 해요` 문구가 파란색으로 보인다.
- [ ] 타이머 idle·setting 화면에서 변기와 시작 버튼이 화면 중앙에 모여 보인다(상단에 치우치지 않는다).
- [ ] 타이머 화면 헤더에 흰색·파란 테두리의 `화캉스` 워드마크가 끊김 없이 보인다.
- [ ] 주요 버튼이 알약형 픽셀 게임 버튼 스타일(하이라이트·그림자·광택)로 보인다.
- [ ] 부처되기 오늘의 문장 화면에 날짜·시각, `오늘의 부처되기 문장` 라벨이 중앙에 보인다.
- [ ] 문장 영역에 박스 테두리가 없다.
- [ ] 문장 영역을 탭하면 바로 입력할 수 있고 별도 입력창이 보이지 않는다.
- [ ] 문장 영역 하단에 변기와 `오늘도 쉽지 않다.` 말풍선이 보인다.
- [ ] 완료 목록에서 항목을 선택하면 재입력 없이 완료 화면이 바로 보인다.
- [ ] 키보드로 입력 요소에 포커스하면 문장 영역에 포커스 링이 보인다.
