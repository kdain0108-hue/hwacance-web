# 타이머 상세 사양

| 항목 | 내용 |
| --- | --- |
| 문서 ID | SPEC-TIMER |
| 버전 | 1.0 |
| 상위 문서 | [PRD.md](../PRD.md) |
| 공통 사양 | [platform-and-ux.md](./platform-and-ux.md) |

## 1. 목적

사용자가 닫힌 픽셀 변기에서 휴식을 시작하고,
열린 변기와 원형 진행률로 남은 시간을 이해한 뒤 체크아웃하도록 돕는다.

## 2. 성공 조건

- 첫 방문 사용자가 설명 없이 10초 안에 10분 타이머를 시작한다.
- 활성 페이지에서 완료 표시 오차가 ±1초 이내다.
- 원형 진행률과 숫자만 보고 남은 시간을 이해한다.
- 새로고침이나 탭 복귀 후 실제 종료 시각을 기준으로 상태를 복원한다.

## 3. 상태 모델

```text
idle
  └─ open settings → setting
setting
  ├─ start → running
  └─ cancel → idle
running
  ├─ pause → paused
  ├─ stop → idle
  └─ remaining <= 0 → completed
paused
  ├─ resume → running
  └─ stop → idle
completed
  ├─ add 5 minutes → running
  └─ finish → idle
```

| 상태 | 핵심 표시 | 허용 행동 |
| --- | --- | --- |
| idle | 닫힌 픽셀 변기, 시작 버튼 | 시간 설정 열기 |
| setting | 닫힌 변기, 시간 선택 | 시작, 취소 |
| running | 열린 변기, 감소 링, 남은 시간 | 일시정지, 그만 쉬기 |
| paused | 열린 변기, 멈춘 링, 남은 시간 | 다시 시작, 그만 쉬기 |
| completed | 열린 변기, 체크아웃 문구, 빈 링 | 체크아웃, 5분 연장 |

## 4. 픽셀 변기와 시작 진입

| ID | 요구사항 |
| --- | --- |
| TIM-01 | idle 중앙에 닫힌 상태의 픽셀 변기를 표시한다. |
| TIM-02 | 닫힌 변기 위에 `화캉스 시작하기` 버튼을 배치한다. |
| TIM-03 | 시작하기 버튼은 시간 설정 UI를 연다. |
| TIM-04 | setting 상태에서도 픽셀 변기는 닫힌 상태를 유지한다. |
| TIM-05 | 시간 설정 후 실제 타이머가 시작될 때 픽셀 변기를 열린 상태로 전환한다. |
| TIM-06 | 픽셀 그래픽은 확대 시 흐려지지 않도록 가장자리 보간을 사용하지 않는다. |
| TIM-07 | 변기 그래픽은 장식으로 처리하고 시간과 버튼에 별도 접근성 이름을 제공한다. |

## 5. 시간 설정

| ID | 요구사항 |
| --- | --- |
| TIM-08 | `5분`, `10분`, `15분` 프리셋을 제공한다. |
| TIM-09 | 기본 선택값은 `10분`이다. |
| TIM-10 | `직접 입력`으로 1~60분 정수를 설정할 수 있다. |
| TIM-11 | 직접 입력을 선택하면 숫자 키보드를 우선 표시한다. |
| TIM-12 | 빈 값과 숫자가 아닌 값은 유효하지 않다. |
| TIM-13 | 1 미만과 60 초과 값은 유효하지 않다. |
| TIM-14 | 유효하지 않은 값에서는 시작 버튼을 비활성화한다. |
| TIM-15 | 오류 원인을 입력란 가까이에 텍스트로 표시한다. |
| TIM-16 | 프리셋과 직접 입력 중 마지막으로 선택한 하나만 활성화한다. |

## 6. 시작

| ID | 요구사항 |
| --- | --- |
| TIM-17 | 시간 설정의 `쉬기 시작`을 누르면 running 상태로 전환한다. |
| TIM-18 | 시작 시 `endAt = now + duration`을 저장한다. |
| TIM-19 | 시작과 동시에 설정 UI를 접고 열린 픽셀 변기를 표시한다. |
| TIM-20 | 브라우저가 지원하면 화면 켜짐 유지를 요청한다. |
| TIM-21 | 화면 켜짐 유지 실패는 타이머 시작을 막지 않는다. |
| TIM-22 | 실행 화면에 `정확한 알림을 받으려면 화면을 켜두세요`를 표시한다. |

## 7. 시간 계산

남은 시간의 원본 공식:

```text
remainingMs = max(0, endAt - currentTime)
progress = remainingMs / durationMs
```

| ID | 요구사항 |
| --- | --- |
| TIM-23 | 반복 호출 횟수를 누적해 시간을 계산하지 않는다. |
| TIM-24 | 화면은 약 1초마다 갱신하되 매번 현재 시각으로 다시 계산한다. |
| TIM-25 | 페이지가 다시 보이면 즉시 남은 시간을 다시 계산한다. |
| TIM-26 | 남은 시간이 0 이하이면 completed 상태로 한 번만 전환한다. |
| TIM-27 | 시스템 시각 변경 후에도 새 현재 시각과 저장된 종료 시각을 사용한다. |

## 8. 원형 진행 표시

| ID | 요구사항 |
| --- | --- |
| TIM-28 | running 상태에서 열린 픽셀 변기 주변에 원형 링을 표시한다. |
| TIM-29 | 링은 애플 타이머처럼 시계 방향 기준으로 실시간 감소한다. |
| TIM-30 | 진행 링의 활성 색상은 `#6485F6`이다. |
| TIM-31 | paused 상태에서는 링의 현재 위치를 유지한다. |
| TIM-32 | completed 상태에서는 링을 비운다. |
| TIM-33 | 링과 함께 남은 시간을 `MM:SS`로 표시한다. |
| TIM-34 | 60분은 `60:00`으로 표시한다. |
| TIM-35 | 숫자는 폭이 변해도 중앙 정렬이 흔들리지 않게 한다. |
| TIM-36 | 모션 감소 환경에서도 시간 변화는 텍스트로 명확히 전달한다. |

## 9. 실행 제어

### 8.1 일시정지

| ID | 요구사항 |
| --- | --- |
| TIM-37 | 일시정지 시 현재 remainingMs를 저장한다. |
| TIM-38 | 일시정지 후 기존 endAt은 시간 원본으로 사용하지 않는다. |
| TIM-39 | 일시정지 상태임을 문구와 버튼 상태로 표시한다. |

### 8.2 다시 시작

| ID | 요구사항 |
| --- | --- |
| TIM-40 | 다시 시작 시 `endAt = now + pausedRemainingMs`로 갱신한다. |
| TIM-41 | 갱신한 endAt을 저장하고 running으로 전환한다. |

### 8.3 그만 쉬기

| ID | 요구사항 |
| --- | --- |
| TIM-42 | `그만 쉬기`는 확인 모달 없이 idle로 전환한다. |
| TIM-43 | 종료 예정 시각과 일시정지 잔여 시간을 제거한다. |
| TIM-44 | idle 복귀 시 픽셀 변기를 닫힌 상태로 되돌린다. |
| TIM-45 | 마지막 선택 시간은 현재 세션에서 유지할 수 있다. |
| TIM-45a | `그만 쉬기` 또는 체크아웃으로 idle에 돌아가면 눈치껏 쉬자에 화장쉼이 자동 기록된다. 상세는 [break-tracker.md](./break-tracker.md)를 따른다. |

## 10. 화면 이동과 새로고침

| ID | 요구사항 |
| --- | --- |
| TIM-46 | 부처되기 화면으로 이동해도 running 상태를 유지한다. |
| TIM-47 | 새로고침 후 저장된 endAt이 미래면 열린 변기의 running을 복원한다. |
| TIM-48 | 저장된 endAt이 과거면 completed를 복원한다. |
| TIM-49 | pausedRemainingMs가 있으면 paused를 복원한다. |
| TIM-50 | 손상되거나 해석할 수 없는 저장값은 제거하고 idle로 복구한다. |

## 11. 완료

| ID | 요구사항 |
| --- | --- |
| TIM-51 | 완료 시 `화캉스 체크아웃 해야 해요`를 크게 표시한다. |
| TIM-52 | 완료 상태에서는 열린 변기와 빈 원형 링을 유지한다. |
| TIM-53 | 페이지가 활성 상태면 짧은 완료음을 재생한다. |
| TIM-54 | 지원 브라우저에서는 짧은 진동 패턴을 한 차례 요청한다. |
| TIM-55 | 진동 실패나 미지원은 오류로 노출하지 않는다. |
| TIM-56 | ASMR이 재생 중이면 완료음 동안 음량을 잠시 낮춘다. |
| TIM-57 | 완료음 후 ASMR을 이전 재생 상태로 복원한다. |
| TIM-58 | 기본 행동 `체크아웃`을 제공한다. |
| TIM-59 | 보조 행동 `5분 더 쉬기`를 제공한다. |
| TIM-60 | 체크아웃 시 idle로 돌아가며 변기를 닫는다. |
| TIM-61 | 5분 연장은 열린 상태에서 새 5분 타이머를 시작한다. |

## 12. 웹 제약

| 상태 | 기대 동작 |
| --- | --- |
| 활성 페이지 | 완료 표시, 가능한 완료음과 진동 |
| 다른 탭·다른 앱 | 정시 알림을 보장하지 않음 |
| 화면 잠금 | 실행·오디오·진동을 보장하지 않음 |
| 전원 종료 | 모든 웹 동작 불가능 |

백그라운드에서 종료된 경우 복귀 시 다음 순서로 처리한다.

1. 현재 시각과 endAt을 비교한다.
2. 남은 시간이 0 이하면 completed로 전환한다.
3. 지나간 시간만큼 자동 연장하지 않는다.
4. 실제 정시 알림이 전달되었다고 기록하지 않는다.

## 13. 오류 및 경계값

| 상황 | 동작 |
| --- | --- |
| 0, 음수, 60 초과 입력 | 시작 차단과 오류 문구 |
| 소수 입력 | 정수 분 입력 안내 |
| 연속 시작 탭 | 하나의 타이머만 생성 |
| 완료 전후 중복 이벤트 | completed 전환과 완료 효과를 한 번만 실행 |
| 로컬 저장 실패 | 현재 메모리 상태로 계속 실행 |
| 진동 API 예외 | 무시하고 화면 완료 유지 |
| 오디오 재생 거부 | 화면 완료 유지 |
| 화면 깨우기 해제 | 안내 유지, 시간 계산 계속 |

## 14. 접근성

- 원형 링만으로 남은 시간을 전달하지 않는다.
- 실행 상태와 버튼 이름을 스크린 리더가 읽을 수 있게 한다.
- 상태 변화가 과도하게 반복 안내되지 않게 한다.
- 버튼 터치 영역은 최소 44×44px다.
- 완료 상태는 색상, 문구, 행동 버튼을 함께 바꾼다.

## 15. 검수 시나리오

- [ ] idle에서 닫힌 픽셀 변기와 `화캉스 시작하기`가 보인다.
- [ ] 시간 설정 중 변기는 닫혀 있고 시작 후 열린다.
- [ ] 기본값 10분으로 시작할 수 있다.
- [ ] 1분과 60분 직접 입력이 시작된다.
- [ ] 0분, 61분, 문자, 소수 입력이 차단된다.
- [ ] 가짜 시계를 사용한 시간 계산 단위 테스트가 통과한다.
- [ ] 일시정지 동안 남은 시간이 줄지 않는다.
- [ ] 다시 시작 후 저장된 잔여 시간만큼 진행된다.
- [ ] 그만 쉬기 후 완료 효과가 발생하지 않는다.
- [ ] 10회 활성 페이지 테스트가 모두 ±1초 이내에 완료 표시된다.
- [ ] 열린 변기 주변 원형 링이 실시간으로 감소한다.
- [ ] 화면 전환 후 남은 시간과 링 위치가 맞다.
- [ ] 새로고침 후 running, paused, completed를 각각 복원한다.
- [ ] 백그라운드 종료 후 복귀 즉시 completed가 표시된다.
- [ ] 진동 미지원 환경에서도 완료 행동을 사용할 수 있다.
- [ ] ASMR 재생 중 완료음 처리 후 ASMR 상태가 복원된다.
- [ ] 완료 시 `화캉스 체크아웃 해야 해요`가 표시된다.
- [ ] 체크아웃 시 변기가 닫히고 idle로 돌아간다.
- [ ] 5분 연장이 열린 상태에서 새 5분 타이머를 시작한다.
