# ASMR 상세 사양

## 1. 목적

사용자가 타이머와 부처되기 필사 중 원할 때만
잔잔한 배경음을 한 번의 탭으로 켜고 끌 수 있게 한다.

## 2. 범위

MVP는 다음만 제공한다.

- 단일 ASMR 음원
- 전역 ON/OFF
- 반복 재생
- 타이머 완료음과의 간단한 음량 조정
- 재생 실패 처리

음원 선택, 재생 목록, 사용자 음량 슬라이더, 자동 재생은 제공하지 않는다.

## 3. 위치와 표시

| ID | 요구사항 |
| --- | --- |
| AUD-01 | 모든 주요 화면 오른쪽 상단에 ASMR 토글을 둔다. |
| AUD-02 | 타이머와 부처되기 화면에서 같은 위치와 형태를 사용한다. |
| AUD-03 | 현재 상태를 `ASMR ON` 또는 `ASMR OFF`로 표시한다. |
| AUD-04 | 접근성 이름은 다음 동작인 `ASMR 켜기` 또는 `ASMR 끄기`다. |
| AUD-05 | 상태를 색상만으로 표현하지 않는다. |
| AUD-06 | 터치 영역은 최소 44×44px다. |

## 4. 상태 모델

```text
off
  └─ user turns on → loading
loading
  ├─ playback starts → playing
  ├─ user turns off → off
  └─ load/play failure → error → off
playing
  ├─ user turns off → off
  ├─ browser suspends → suspended
  └─ playback error → error → off
suspended
  ├─ browser resumes playback → playing
  └─ explicit user action required → off
```

## 5. 기본 동작

| ID | 요구사항 |
| --- | --- |
| AUD-07 | 최초 페이지 진입 상태는 OFF다. |
| AUD-08 | 사용자가 ON을 직접 누른 뒤에만 재생을 요청한다. |
| AUD-09 | 브라우저 자동 재생 제한을 우회하지 않는다. |
| AUD-10 | 재생이 시작된 뒤 토글을 playing 상태로 확정한다. |
| AUD-11 | ON 요청 중에는 짧은 loading 상태를 표시할 수 있다. |
| AUD-12 | OFF를 누르면 300ms 이내에 소리를 멈춘다. |
| AUD-13 | OFF 후 재생 위치를 초기화할 수 있다. |
| AUD-14 | 새로고침 후에는 이전 상태와 관계없이 OFF로 시작한다. |

## 6. 전역 재생

| ID | 요구사항 |
| --- | --- |
| AUD-15 | 애플리케이션 전체에서 하나의 오디오 인스턴스를 사용한다. |
| AUD-16 | 화면 전환으로 새 오디오 인스턴스를 만들지 않는다. |
| AUD-17 | 타이머에서 부처되기로 이동해도 재생을 이어간다. |
| AUD-18 | 부처되기에서 타이머로 이동해도 재생을 이어간다. |
| AUD-19 | 두 음원이 겹쳐 재생되지 않게 한다. |
| AUD-20 | UI 상태와 실제 오디오 재생 여부를 주기적으로 일치시킨다. |

## 7. 음원

| ID | 요구사항 |
| --- | --- |
| AUD-21 | 자연스럽고 자극이 적은 단일 음원을 사용한다. |
| AUD-22 | 반복 구간이 눈에 띄지 않도록 편집한다. |
| AUD-23 | 사용자가 ON을 누르기 전 전체 파일 다운로드를 강제하지 않는다. |
| AUD-24 | 모바일 네트워크를 고려해 적절히 압축한다. |
| AUD-25 | 웹 배포와 반복 재생이 허용된 라이선스만 사용한다. |
| AUD-26 | 음원 출처와 라이선스 증빙을 저장소 밖의 운영 기록에 보관한다. |

## 8. 타이머 완료와의 관계

| ID | 요구사항 |
| --- | --- |
| AUD-27 | ASMR playing 중 완료음이 시작되면 ASMR 음량을 잠시 낮춘다. |
| AUD-28 | 완료음이 끝나면 기존 ASMR 음량으로 복원한다. |
| AUD-29 | 완료음 재생 실패가 ASMR을 멈추게 하지 않는다. |
| AUD-30 | 사용자가 완료 중 OFF를 누르면 복원하지 않고 OFF를 유지한다. |

## 9. 백그라운드와 잠금

- 브라우저와 운영체제가 백그라운드 오디오를 중단할 수 있다.
- 화면 잠금 후 재생 지속을 보장하지 않는다.
- 중단된 재생을 사용자 동작 없이 강제로 다시 시작하지 않는다.

| ID | 요구사항 |
| --- | --- |
| AUD-31 | 페이지 복귀 시 실제 재생 여부를 확인한다. |
| AUD-32 | 자동 재개가 허용되면 playing 상태를 유지한다. |
| AUD-33 | 사용자 동작이 필요하면 OFF로 바꾸고 다시 누르도록 안내한다. |

## 10. 오류 처리

| 상황 | 동작 |
| --- | --- |
| 음원 로드 실패 | OFF 복원과 `소리를 불러오지 못했어요` 표시 |
| 재생 권한 거부 | OFF 복원과 다시 누르기 안내 |
| 재생 중 오류 | OFF 복원과 짧은 오류 메시지 |
| 네트워크 단절 전 미로드 | 재생 실패 처리 |
| 네트워크 단절 전 로드 완료 | 브라우저 버퍼 범위에서 재생 |
| 빠른 ON/OFF 반복 | 마지막 사용자 동작을 최종 상태로 적용 |

오류 메시지는 타이머나 작성 중인 문장을 가리는 모달로 표시하지 않는다.

## 11. 개인정보

- 마이크 권한을 요청하지 않는다.
- 주변 소리를 녹음하지 않는다.
- 재생 여부와 사용 시간을 서버로 전송하지 않는다.
- 개인별 청취 기록을 저장하지 않는다.

## 12. 접근성

- 토글의 현재 상태와 다음 동작을 읽을 수 있어야 한다.
- 로딩과 오류 상태를 텍스트로 제공한다.
- ON/OFF 변경에 과도한 애니메이션을 사용하지 않는다.
- 소리를 듣지 못해도 다른 기능 사용에 손실이 없어야 한다.

## 13. 검수 기준

- [ ] 첫 방문과 새로고침 후 OFF다.
- [ ] 사용자 동작 전 오디오 요청이 발생하지 않는다.
- [ ] ON 후 실제 재생이 시작될 때 UI가 playing을 표시한다.
- [ ] OFF 후 300ms 안에 재생이 멈춘다.
- [ ] 두 주요 화면의 오른쪽 상단에 같은 토글이 있다.
- [ ] 화면을 오가도 하나의 음원만 이어서 재생된다.
- [ ] 빠른 ON/OFF 후 마지막 동작과 실제 상태가 일치한다.
- [ ] 로드 실패와 재생 거부 후 OFF로 복구한다.
- [ ] ASMR 중 타이머 완료음이 구분되어 들린다.
- [ ] 완료 중 OFF를 누르면 ASMR이 다시 켜지지 않는다.
- [ ] 백그라운드 복귀 후 UI와 실제 재생 상태가 일치한다.
- [ ] 마이크 권한을 요청하지 않는다.
- [ ] 음원 라이선스 증빙이 확인되어 있다.
