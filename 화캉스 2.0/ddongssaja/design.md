# 디자인 명세 (design.md)

## 1. 목적

똥싸자 MVP의 색상, 타이포그래피, 배경 패턴, 화면별 시각 구성 규칙을 정의한다.
기능 동작은 각 기능 사양([`specs/`](./specs))이 소유하며, 이 문서는 시각적 표현만 소유한다.

## 2. 범위

- 색상 토큰
- 타이포그래피(픽셀 폰트 적용 범위)
- 배경 패턴(모눈 그리드)
- 버튼 컴포넌트 스타일
- 로고(브랜드 워드마크) 배치
- 팝업(모달) 컴포넌트
- 이미지 에셋 매핑

| DSN-03 | 타이머·부처되기 배경 그리드는 흰색 `#FFFFFF` 바탕에 옅은 파란색 선 `#E3EDFF`을 사용한다. |
| DSN-04 | 눈치껏 쉬자의 `아직은 눈치 봐야 해요` 문구는 `#6485F6`으로 표시한다. |

## 4. 타이포그래피

| ID | 요구사항 |
| --- | --- |

### 4.1 서체 출처와 라이선스

- 서체 파일 출처: `C:\Users\user\Desktop\MY\활동 아카이빙\PPT\FONT`(사용자 로컬 보관 폰트)

## 5. 배경 패턴 — 모눈 그리드

| ID | 요구사항 |
| --- | --- |
| DSN-09 | 파란 선 모눈 그리드를 배경으로 사용한다. |
| DSN-10 | 그리드 격자 간격은 22px, 선 두께는 1px다(연한 선으로 본문을 가리지 않는다). |

## 6. 버튼 컴포넌트

기존 앱(화장쉼 시작하기 등)에서 쓰인 알약형 버튼 스타일을 그대로 따른다.
똥싸자 시작 화면의 "똥 싸기 시작" 버튼([SPEC 01](./specs/01-core-gameplay.md))과 결과 화면의
"다시 시작" 버튼([SPEC 05](./specs/05-result-screen.md))에도 동일한 스타일을 적용한다.

| ID | 요구사항 |
| --- | --- |
| DSN-12 | 버튼은 완전한 알약(캡슐) 형태다. `border-radius`는 버튼 높이의 50%로, 좌우 끝이 완전히 둥글다. |
| DSN-13 | 버튼 배경은 위(밝은 파란색)에서 아래(`#6485F6`)로 이어지는 그라디언트를 사용하고, 테두리는 보조 파란색 `#4C6BDB`로 감싼다. |
| DSN-14 | 버튼 좌상단에는 반투명 흰색 광택(하이라이트) 효과를 넣어 입체감을 준다. |
| DSN-15 | 버튼 라벨은 흰색, 굵게(Bold), 중앙 정렬하며 [4장 타이포그래피](#4-타이포그래피) 규칙(`Mona12`/`Mona12TextKR`)을 따른다. |
| DSN-16 | 버튼 하단에는 은은한 그림자(box-shadow)를 넣어 배경 위에 떠 있는 느낌을 준다. |
| DSN-17 | 버튼 표준 크기는 높이 약 48px, 최소 너비 약 180px, 폰트 크기 약 16px다(팝업 카드 안에 들어가기 적당한 크기로, 이전 시안보다 축소됨). |

### 6.1 구현 예시

- [`start-button.svg`](./start-button.svg): 위 규칙을 적용한 "똥 싸기 시작" 버튼 예시 에셋
  (DSN-17 축소 이전 크기 기준 — 실제 구현은 DSN-17 크기를 따른다).

## 7. 로고 (브랜드 워드마크)

| ID | 요구사항 |
| --- | --- |
| DSN-18 | 화면 좌상단에 `똥 싸자.png` 워드마크 로고를 항상 노출한다. 시작/플레이/결과 화면 공통이며, 화면 전환과 무관하게 계속 보인다. |
| DSN-19 | 로고 너비는 약 60px 내외로 작게 표시하고, 화면 상단에서 좌측 12px, 상단 10px 정도의 여백을 둔다. 플레이 화면에서는 점수 표시(HUD)가 로고와 겹치지 않도록 여백을 확보한다. |

## 8. 팝업(모달) 컴포넌트

시작 화면과 결과 화면은 화면 전체에 텍스트가 흩어진 형태가 아니라, 하나의 사각형
카드(팝업) 안에 모든 콘텐츠를 담아 표시한다. 플레이 화면(게임 진행 중)은 팝업이 아닌
전체 화면 그대로 사용한다.

| ID | 요구사항 |
| --- | --- |
| DSN-20 | 시작 화면과 결과 화면의 모든 콘텐츠(제목, 설명, 버튼 등)는 하나의 팝업 카드 안에 담는다. |
| DSN-21 | 팝업 카드는 흰 배경, 파란색(`#6485F6`) 테두리, 둥근 모서리(약 20px), 은은한 그림자를 사용해 배경 그리드 위에 떠 있는 느낌을 준다. |
| DSN-22 | 팝업 뒤 배경은 어둡게 가리지 않는다. [5장 배경 패턴](#5-배경-패턴--모눈-그리드)의 흰 그리드 배경을 그대로 유지하고, 카드의 테두리·그림자만으로 전경과 배경을 구분한다. |
| DSN-23 | 좌상단 로고([7장](#7-로고-브랜드-워드마크))는 팝업 카드보다 항상 위(최상단)에 표시되어, 어느 화면에서도 가려지지 않는다. |
| DSN-24 | 결과 화면의 총 성공 개수 문구(예: "총 37개의 똥을 변기에 넣었습니다!")는 성공 개수 값의 자릿수와 무관하게 항상 한 줄로 표시하며, 줄바꿈되지 않는다. |
