# SPEC 03. 생명력 시스템 (하트 3개)

상위 문서: [PRD.md](../PRD.md) · 관련: [SPEC 01 — 코어 플레이](./01-core-gameplay.md)

## 목적

한 번의 실수로 즉시 게임이 끝나던 기존 구조 대신, 약간의 여유를 주는 하트 기반
생명력 시스템을 통해 플레이 지속 시간을 늘리고 좌절감을 줄인다.

## 1. UI 표시

- 화면 **우측 상단**에 하트 아이콘 **3개**를 표시한다.
- 초기 상태(게임 시작 시): 하트 3개 모두 **채워진 상태**.
- 생명력이 감소할 때마다 채워진 하트 하나가 **빈 하트**로 바뀐다 (오른쪽 또는 정해진 순서부터, 구현 시 확정).

## 2. 생명력 감소 조건

다음 두 가지 상황에서 생명력이 1 감소한다.

1. **휴지를 변기에 넣은 경우** — 낙하하는 휴지가 변기 영역에 도달했을 때
2. **똥을 놓친 경우** — 낙하하는 똥이 변기에 들어가지 못하고 화면 밖으로 낙하했을 때

> 참고: 휴지를 놓친 경우(휴지가 변기에 안 들어가고 화면 밖으로 떨어진 경우)는
> 페널티가 없다. 휴지는 "피해야 하는" 대상이지, "받아야 하는" 대상이 아니다.

## 3. 생명력 소진과 게임 종료

- 하트 3개가 모두 빈 하트가 되면(생명력 0) 게임이 즉시 종료된다.
- 종료 즉시 결과 화면으로 전환된다. (상세: [SPEC 05 — 결과 화면](./05-result-screen.md))

## 4. 생명력과 점수의 관계

- 생명력 감소는 점수(성공 개수)에 영향을 주지 않는다. 점수는 오직 똥을 성공적으로
  받았을 때만 증가한다.
- 생명력 감소는 난이도 구간 계산에도 영향을 주지 않는다. 난이도는 성공 개수 기준으로만 상승한다.
  (상세: [SPEC 02 — 난이도 상승](./02-difficulty-progression.md))

## 5. 구현 체크리스트

- [ ] 게임 시작 시 하트 3개 모두 채워진 상태로 초기화한다.
- [ ] 휴지를 받으면 하트가 1개 감소하고, 즉시 UI에 반영된다.
- [ ] 똥을 놓치면 하트가 1개 감소하고, 즉시 UI에 반영된다.
- [ ] 하트가 0이 되는 순간 낙하물 생성을 멈추고 결과 화면으로 전환한다.
- [ ] 하트 감소 애니메이션/이펙트(선택 사항)를 넣을 경우 판정 로직과 별도로 처리하여
      로직이 연출에 종속되지 않게 한다.
